Abhi Ayur walkthrough site
--------------------------
Static site: upload this whole folder to any host (Vercel, Netlify, cPanel).
- index.html   page and all text content
- styles.css   colours, fonts, layout
- tour.js      scroll walkthrough (canvas frame player)
- media/       room photos and video frames (desktop "d" and phone "m" sets)

Visitors with "reduce motion" turned on see the rooms as a simple list instead.
To change the room order or scroll speed, edit CONFIG at the top of tour.js.
